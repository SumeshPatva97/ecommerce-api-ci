## 22. Method and limitations

1. **What was searched.** `PROJECT_REQUIREMENTS.md` §5 (all rows); the 248 operations in `docs/openapi/openapi.json`; `src/modules/**`, `src/jobs/**`, `src/core/**`, `src/lib/**`, `prisma/schema.prisma`, the baseline migration and seeds; the names of all `describe`/`it` blocks in `tests/unit/**` and `tests/integration/**` (≈ 1,160 tests), with targeted reads where a name was not enough. Deferrals were taken from `PHASE4-REMAINING-DECISIONS.md`, `PHASE4-MASTER-COMPLETION-ROADMAP.md` §4 and `PHASE3-PHASE4-MASTER-PROGRESS-REPORT.md` §2.
2. **Nothing was executed.** No tests, builds, Prisma, database, network or Git commands were run. No `.env*` or secret file was opened. Test evidence means "a test with this name exists and its body was judged, by reading, to target the behaviour" — not "the test passes".
3. **Tests are mocked.** Integration tests use Supertest with a mocked Prisma client and fake providers. They do not prove MySQL constraints, locking (`FOR UPDATE`), real concurrency, real gateway/courier/e-mail/WhatsApp/Cloudinary behaviour, performance targets (p95, label timing) or production behaviour.
4. **Single-instance assumptions.** The rate limit, permission cache and re-auth markers use an in-process store (`src/core/store/memoryStore.ts`). Jobs run in one dedicated worker (RD-12). Idempotency keys are stored in the DB.
5. **Classification is a draft.** Scope (API/FE/MIXED/DB/INFRA) and status are one reviewer's judgement from static reading. Rows marked T may still have gaps that were not visible from the code. The owner must review this before it is used as G4 evidence.
6. **Out of scope.** S/C/W rows (32) are not mapped. Frontend repositories were not inspected.
